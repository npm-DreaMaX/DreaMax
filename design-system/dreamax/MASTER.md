Reviewed 2026-09-22. The user correction is authoritative: preserve the personal homepage composition and original content. LLM Training is a peer section, not a replacement homepage. Remove only the explicitly retired Magic Corner and Machine Learning categories; redirect their old URLs.

## Visual system

Personal homepage: centered typography-only DreaMax wordmark, code motif, quote, research, projects, tools and updates. The latest user feedback explicitly rejects the flanking logo glyphs, star/orbit background, old typography and dot navigation. Remove those glyphs and the dot navigation. Use self-hosted Outfit for display, Inter and Noto Sans SC for readable English and Chinese. Porcelain (#f7f9fd), ink (#172033) and cobalt (#3158df), with a navy project section. New architectural background: pale blue planes with bounded pointer parallax; no stars, grain or orbital lines. Preserve all existing content. Three actual projects replace empty cards.

Training portal: the already-developed immersive experience, moved to /llm-training/. Large editorial type, original interactive metallic sculpture, paper images, reading paths and experiments. Full reader at /fieldwork/; obvious links back to the parent space and personal homepage.

## Interaction

Floating white command navigation with direct peer links, a keyboard-accessible LLM learning-route disclosure, and the full six-section index; full-screen menu with keyboard-equivalent previews and direct learning paths; search across projects, original research, papers and tools. 280 ms outbound curtain and 580 ms incoming reveal; Esc can cancel departure. Normal anchors without JavaScript, instant navigation for reduced motion, reset on browser history restoration. Avoid hijacking reader SPA links.

Three.js: original parametric mesh, 30 fps cap, DPR capped at 1.6, pause offscreen and in background, keyboard controls and static SVG fallback. Dialog focus remains trapped and restores to the opener.
