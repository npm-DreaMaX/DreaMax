# Content contract
Each article is a JSON file in src/content/ with fields:
slug (unique kebab-case), title (Chinese), subtitle (Chinese), track (data|pretraining|midtraining|posttraining|agentic|evaluation|serving|systems|foundations), order (number), minutes (number), difficulty ('进阶'|'研究'|'快速补充'), description, prerequisites (array of short strings), learningGoals (array), sources (array of source IDs), lab (optional string: gradients|data-mixture|preference|agent-loop|rollout|evaluation|moe), body (Markdown string).
Use ## headers with Chinese text; cross references use /learn/slug. References link /sources#source-id inline near exact supported claims. Original synthesis explicitly label **课程分析**. Official unknowns explicit. Educational code clearly labeled. No fabricated configs/functions. Include concrete failure metrics, exercise, run command if linking labs. Markdown supports math ($ and $$), fenced python/bash, GFM tables. For flowcharts use fenced `flow` with one node per line, ASCII arrows optional (renderer stacks connected nodes). Source excerpts should be brief and license-attributed; prefer read guides over copying.
Source IDs agreed: verl, verl-agent-loop, verl-grpo, trl-dpo, olmo-core, olmo3, dolma, megatron-moe, vllm-scheduler, swebench, swe-agent, dpo-paper, grpo-paper, r1-report, torch-autograd, flashattention, chinchilla, fineweb, olmo2, yarn, instructgpt, process-supervision, agent-lightning.
Sources JSON (src/data/sources.json) array: id,title,organization,type ('官方源码'|'论文'|'官方文档'|'技术报告'|'模型卡'),url,published (YYYY-MM-DD or '未标注'),accessed ('2026-09-22'),repository (URL or null),version (SHA/version or null),license (verified or '未核验'),supports (array strings),chapters (array slugs),evidence ('源码观察'|'官方事实'|'论文实验'),file (optional),symbol(optional),notes(optional), excerpt(optional <= brief 10-15 source code lines), excerptStart(optional number).
Only research agent owns sources.json; other agents list additional needed sources in research/source-requests-<name>.json. All authors may use IDs above, coordinating verified facts.
